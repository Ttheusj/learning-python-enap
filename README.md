# Learning with Python — ENAP

## Sobre o repositório
Este repositório foi criado para documentar minha evolução no aprendizado de Python, acompanhando o curso **Learning with Python (20 horas)**, oferecido pela Escola Nacional de Administração Pública (ENAP), por meio da Escola Virtual de Governo (EV.G).

## Motivação
Sempre senti que precisava melhorar meus conhecimentos em programação. Apesar de ter uma base em C/C++, percebi que não estava fazendo muito para desenvolver essa habilidade.
Decidi começar pelo Python e utilizar este repositório para registrar minha evolução, dificuldades e aprendizados ao longo do caminho.

## Objetivos
- Aprender os fundamentos da linguagem Python.
- Registrar exercícios e atividades do curso.
- Desenvolver pequenos desafios por conta própria.
- Documentar dificuldades e soluções encontradas.
- Aprender a utilizar Git e GitHub.

## Próximos passos
Após a conclusão do curso, pretendo aplicar os conhecimentos adquiridos em pequenos projetos, especialmente nas áreas de engenharia, energia e análise de dados.
